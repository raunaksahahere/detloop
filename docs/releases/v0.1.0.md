# detloop 0.1.0

First public release of **detloop**, deterministic simulation testing for
Python asyncio services.

## Install

```console
pip install detloop
```

Standard library only; the pytest plugin registers itself when pytest is
installed. Supported: CPython 3.11–3.14 on Linux, macOS and Windows.

## What works

- **Deterministic event loop**: integer-nanosecond virtual time, seeded
  interleaving of nodes that preserves asyncio's FIFO order within each node,
  single-loop `fifo` mode, budgets, deadlock and starvation detection, and a
  wall-clock watchdog for code that never yields.
- **Simulated world**: nodes with addresses and names, crash/restart with
  incarnation generations (crashed code never runs again, even if it ignores
  cancellation), persistent `node.disk`, clock skew and drift.
- **Simulated network**: TCP-like ordered streams with flow control and
  `drain()` backpressure, partitions that stall and retransmit, resets,
  process vs host crash semantics, and a lossy/reordering message bus.
- **Checking**: invariants, operation histories, and a bounded
  linearizability checker that answers valid, invalid or unknown.
- **Exploration and debugging**: multi-process seed exploration with
  deterministic aggregation, SQLite results, JSONL traces, exact replay,
  delta-debugging shrinker with strict replay, and an offline HTML report.
- **pytest and CLI**: `@detloop.simulate`, `--detloop-seed`,
  `--detloop-replay`; `detloop explore | replay | shrink | report`.
- **Compatibility**: aiohttp (client and server) and httpx run over the
  simulated network.

## Find and replay a bug

```console
detloop explore detloop.examples.kv_sim::test_kv_split_brain --seeds 300 --jobs 8
detloop replay .detloop/artifacts/test_kv_split_brain/seed-17/manifest.json --expect-reproduce
detloop shrink .detloop/artifacts/test_kv_split_brain/seed-17/manifest.json
pytest your_tests.py --detloop-seed=17
```

## Measured validation

- Test suite: passing on CPython 3.11.16, 3.12.3, 3.13.15, 3.14.7 (Linux,
  locally) and on the CI matrix (3.11–3.14 × Linux/macOS/Windows; see the CI
  run for this tag's commit).
- Determinism: identical trace hashes in fresh processes under
  `PYTHONHASHSEED` 0, 1 and 4242; serial and parallel exploration agree per
  seed; the declared portable fixture is byte-identical across Python 3.11,
  3.12 and 3.13 locally and is compared across all CI jobs.
- Linearizability checker agrees with an independent brute-force oracle on
  1,500 generated and 675 exhaustively enumerated histories.
- Bug corpus (300 seeds each, CPython 3.12): stale reads found in 66% of
  seeds, lost acknowledged writes in 15%, split brain in 5%; the corrected
  baseline passed all 300.
- Throughput on an AMD Ryzen 5 5600H (12 logical CPUs): ~8.7 KV seeds/s per
  process, ~51 seeds/s with 12 workers; ~0.11 s per seed versus ~6.5 s per
  trial for the same workload on real asyncio with random sleeps. Details and
  limits: `docs/BENCHMARKS.md`.

## Limitations

- Not a sandbox and not a proof: code outside the documented boundary
  (threads, subprocesses, real I/O, C extensions, `datetime.now()`) is either
  rejected or not detected.
- No TLS, IPv6, UNIX sockets, datagram endpoints or disk/fsync model.
- httpx opens a new connection per request over simulated sockets (its pool
  liveness check needs a real file descriptor).
- Byte-identical traces across Python minor versions are not promised;
  pinned seeds are per runtime family.
- Decision-tape shrinking is budget-bounded and often incomplete on
  network-heavy workloads; fault shrinking is effective.

See `docs/IMPLEMENTATION_STATUS.md` and `docs/ROADMAP.md`.
